# 🌱 Grow-My-Therapy

**Grow-My-Therapy** is a responsive therapist landing page built using **Next.js** and **Tailwind CSS**.  
It presents a clean, calming, and user-friendly interface for showcasing mental health services.

<!-- 🔗 **Live Website:** https://growtherapy.netlify.app/ -->

---

## 🧠 About the Project

Grow-My-Therapy is designed to represent a professional therapy website.  
It highlights therapist information, services, and contact details in a structured and approachable way.

This project is suitable for:
- Portfolio showcasing
- Therapist or mental health landing pages
- Practice projects using Next.js

---

## 🚀 Features

- Responsive design for all screen sizes  
- Modern UI with calming layout  
- SEO-friendly Next.js framework  
- Reusable React components  
- Fast deployment with Netlify  

---

## 🛠 Tech Stack

- **Next.js** – React framework
- **React.js** – UI components
- **Tailwind CSS** – Styling
- **TypeScript** – Type safety
- **Netlify** – Deployment
